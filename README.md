# Military Pay Calculator

A Python command line tool that estimates U.S. military monthly pay based on pay grade, years of service, and dependent status.

## What it calculates

- **Base Pay** — based on pay grade and years of service (2024 rates)
- **BAS** — Basic Allowance for Subsistence (flat rate by officer/enlisted)
- **BAH** — Basic Allowance for Housing (varies by grade and dependents)
- **Total estimated monthly pay**

## How to run

```bash
python military_pay_calc.py
```

## Supported pay grades

E-1 through E-7, O-1 through O-3

## Notes

Pay figures are estimates based on 2024 military pay tables and may not reflect exact pay. Actual BAH varies
